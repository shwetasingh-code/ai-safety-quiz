# AI Safety Quiz

A simple C++ quiz project based on basic AI Safety concepts.

## About the Project

This project is a beginner-friendly quiz game that tests basic knowledge of AI and AI Safety.

The quiz includes multiple-choice questions and displays the final score at the end.

## Features

- Multiple-choice questions
- Score calculation
- Instant feedback for answers
- Beginner-friendly C++ project
- Simple console interface

## Concepts Used

- Variables
- Input and Output
- If-Else Statements
- Conditional Logic

## How to Run

1. Compile the program
2. Run the executable file
3. Answer the quiz questions
4. View your final score
